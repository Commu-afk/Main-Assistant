# PRD (Product Requirements Document)

## Цель
Создать локальный оффлайн-ассистент для Windows/Android с поддержкой диалога, голосового ввода/вывода и работы с заметками/задачами без обязательного облака.

## Целевая платформа
- Windows (приоритет для разработки)
- Android (позже)

## MVP (минимально рабочий)
- [x] Чат с локальной LLM (Qwen GGUF) через llama.cpp
- [x] Голосовой ввод (sherpa-onnx zipformer-ru)
- [x] Озвучка ответа (локальный TTS)
- [ ] Хранение истории чата/записей в SQLite (записи — да, история чата — нет)
- [x] Базовый поиск по записям
- [x] Простые напоминания/уведомления (Windows, пока приложение запущено)
- [x] Автоопределение типа записи и срока по голосовой/текстовой команде

## Дальнейшие планы
- [ ] Полнотекстовый поиск (FTS5)
- [ ] Семантический поиск по эмбеддингам
- [ ] Планировщик задач с уведомлениями
- [ ] Настройки выбора моделей, параметров инференса
- [ ] Экспорт/импорт истории

## Ограничения
- Максимально оффлайн-ориентированный
- Модели тяжёлые, не коммитить в git
- Работать на относительно современных ПК/телефонах

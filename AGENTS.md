# AGENTS.md

## Цель проекта
Локальный оффлайн-ассистент. Без обязательного подключения к внешним API в базовом сценарии.

Ключевые компоненты:
- LLM: Qwen в формате GGUF, запуск через llama.cpp
- STT: Whisper (локально)
- TTS: локальный синтез речи с поддержкой русского
- Хранение: SQLite (+ полнотекстовый поиск, с перспективой на семантический)
- Уведомления/планировщик: нативные механизмы платформы
- Интерфейс: Flutter (Android + Windows)

## Правила для агента
- Работай ТОЛЬКО в текущей директории проекта.
- Строго придерживайся структуры:
  - `lib/core/` — конфиг, константы, утилиты, DI, роутинг
  - `lib/data/` — источники данных, репозитории, модели БД
  - `lib/features/` — фичи по модулям (`chat/`, `stt/`, `tts/`, `llm/`, `tasks/`, `settings/`)
  - `lib/shared/` — переиспользуемые виджеты, хелперы, расширения
- Предпочитай простые и явные решения. Минимум лишних абстракций.
- Перед крупными правками обнови `docs/TODO.md`.
- **НИКОГДА** не добавляй в git веса моделей: `*.gguf`, `*.bin`, `*.onnx`, `*.ggml`. Кладём их вне git или в `assets/models/` с явным игнорированием.
- После изменений в Dart-коде по возможности проверяй `flutter analyze`.
- Сначала делай рабочий минимальный прототип под Windows, не забывай про кроссплатформенность.
- Меньше "рефактор на будущее", больше "работает сейчас".

## Команды
- `flutter pub get`
- `flutter run -d windows`
- `flutter analyze`
- `flutter build windows`
